# Poke'Catch 挂机助手 · AutoFarm

面向 [Poke'Catch Online](https://pokecatch-online.netlify.app/) 的用户脚本，提供挂机辅助、进度监控、存档备份与提醒功能。当前版本：**3.9.0**。

## 功能

- 自动处理捕获图鉴卡、普通确认框、礼物选择和进化过场；仅对安全白名单操作，遇到放生、出售、删除、重置等危险操作时不会自动点击。
- 自动进入游戏、保持游戏速度、定时保存，并在检测到新闪光、活动、徽章、停滞等事件时提醒。
- 显示章节进度、捕获/战斗/金钱速率、队伍状态和事件日志；提供队伍建议与宝可梦评分角标。
- 可自动维持树果增益、切换残血队员、运行游戏城自动模式。残血自动换人和游戏城自动模式默认关闭；游戏城模式会消耗游戏内金钱。
- 定期备份和恢复游戏存档，统计离开期间收益，并支持 Bark、ntfy、Telegram 推送。
- 提供昼夜提示、夜间零捕获检查、停滞检测、屏幕常亮及可选后台保活。
- **3.7 新增**：商店采购——按需买经验糖（自动挑「每 ₽ 经验」最高的已解锁档），可设囤货颗数、金钱下限、每日花销上限，带「立即采购一次」和「商店探测」。
  这家店的货架是**固定的**（不刷新、不轮换），而且**不卖树果**：钱店只有经验糖、进化石和一次性进化道具。
  > 3.8.1 修正：3.7 曾把树果当成商店商品来「补货」，那是读错了常量（`BERRY_BADGES` 是树果增益的徽章门槛，不是货架），实际一个都买不到。现已改为采购经验糖；进化石不自动买（脚本不知道你要进化谁，买了大概率闲置）。
- **3.7 新增**：每日收益账本——按天记录收入、支出、捕获、孵化、进化与在线时长，面板显示「今日」一行，可导出 CSV。
- **3.7 新增**：图鉴缺口——按关都/城都/丰缘/神奥统计已开与缺口，并给出最该补的地区。
- **3.7 新增**：培育屋监控——放大槽位/蛋位状态，闪光配对提示，新蛋与长时间空位提醒。
- **3.8 新增**：战斗对位卡——读取 `#arena` 与 `#team-rail`，实时显示双方血量、属性克制、预计回合和胜率。
- **3.8 新增**：智能换人——本场胜率过低或当前宝可梦残血时，自动换上最克制的替补（默认关闭）。
- **3.8 新增**：区域战绩与连败提醒——按章节/节点记录胜负、平均掉血与用时，同一区域连败到阈值提醒换区。
- **3.8 新增**：首发建议——按当前区域敌人池给全队打分，可一键把最佳对位拖到队首（实验，合成拖拽）。
- **3.9 新增**：宝可梦详情「升到下一级」——在队伍里点开任意一只，详情弹窗的经验糖一排末尾会多一个按钮：先把你自己有的糖按「从小到大」吃掉，正好升一级就停；糖不够时弹窗告诉你还差多少经验、买哪种糖最省、要花多少 ₽，你点「购买并使用」它才去买（同样受金钱下限约束），买完自动回到这只继续喂。关掉「缺糖时弹窗询问是否购买」就只吃自己有的糖，绝不花钱。

真实鼠标或键盘操作时，脚本会暂时让出控制权。后台标签页可能被浏览器节流，自动化速度会下降；屏幕常亮和后台保活也无法保证浏览器或设备持续运行。

## 安装

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 打开本仓库中的 [`pokecatch-autofarm.user.js`](./pokecatch-autofarm.user.js)，将源码导入用户脚本管理器并保存。
3. 访问 [Poke'Catch Online](https://pokecatch-online.netlify.app/) 或 [Pages 镜像](https://pokecatch-online.pages.dev/)。页面右上角出现挂机面板即表示脚本已运行。
4. 在面板中打开设置，按需调整自动化功能。

脚本匹配以下地址：

```text
https://pokecatch-online.netlify.app/*
https://pokecatch-online.pages.dev/*
```

## 使用说明

- 面板可拖动、折叠；支持暂停、诊断和队伍建议。
- `Alt + P`：暂停或继续自动化。
- `Alt + H`：显示或隐藏面板。
- 自动刷新默认关闭。启用前建议先使用停滞提醒，以免页面刷新打断游戏流程。
- 推送功能需要在设置中填写对应服务的地址或凭据。推送密钥存放在用户脚本管理器存储中。
- 存档备份同样保存在用户脚本管理器存储中。卸载脚本或清除管理器数据前，请先导出重要备份。

## 隐私与存储

- 游戏存档键：`gachamon-save-v1`。脚本会读取此存档以展示统计、检测事件及执行用户启用的存档操作。
- 脚本配置：`localStorage['pcauto.cfg.v1']`。
- 闪光记录：`localStorage['pcauto.shinies.v1']`。
- 每日收益账本：`localStorage['pcauto.ledger.v2']`（保留最近 90 天，只记数量与金额，不记宝可梦明细）。
- 区域战绩：`localStorage['pcauto.battles.v1']`（保留最近 60 个区域，只记胜负、掉血与用时）。
- 自动备份及推送凭据使用 Tampermonkey / Violentmonkey 提供的 GM 存储。
- 启用推送后，脚本会向所选推送服务发送已启用的事件通知；请只配置自己信任的服务。

## 权限

脚本通过 GM 存储 API 保存设置之外的私密数据，并通过 GM 网络请求 API 向 `api.day.app`、`ntfy.sh` 或 `api.telegram.org` 发送推送。元数据还声明了通用网络连接权限，以支持推送服务地址配置。

## 故障排查

- 确认脚本已启用，并且当前页面地址匹配上面的两个域名。
- 如果面板提示页面停滞，先确认游戏页面在前台运行；后台标签页受浏览器节流时可能无法满速推进。
- 如果游戏不再继续，检查是否出现脚本无法安全识别的弹窗。危险操作和未知按钮需要由玩家手动处理。
- 推送未送达时，检查服务地址、令牌及对应事件开关。

## 更新日志

### 3.9.0

- 新增「升到下一级」按钮：挂在宝可梦详情弹窗（`.modal.mon-modal .dc-candies`）里，每拍检查弹窗是否开着，开了就把按钮补上（升级后弹窗会重绘，所以会反复补）。
- 吃糖逻辑：只点游戏自己的 `.dc-candy` 按钮（不写存档），按 `exp-candy-s → m → xl → big` 从小到大吃，等级一变就停 —— 升级后多出的经验会带进下一级，所以不必精算，但能避免「一颗 MAX 直接跳好几级」。
- 不够时弹窗：从弹窗的「经验值 a / b」读还差多少经验，按「**总花费**最低」而不是单价最低来选档（补 25 万经验 → 1 颗 XL 花 48,000，比 250 颗小糖 300,000 便宜），并受 `shopMoneyFloor` 保留线约束；点「购买并使用」才真的去商店下单。
- 买糖必须回商店（弹窗会挡住页面），所以点详情时记下「队伍第几只」（详情弹窗不暴露 uid），买完按序号点回去、重新开详情、把新糖吃掉。
- 新增开关 `lvAutoBuy`（默认开）：关掉后只吃自己有的糖，绝不花钱。读不到经验条时只报告、不估价（宁可不报，也不乱算钱）。
- 离线自测扩到 128 项断言，新增覆盖数字解析（千分位 / 空格 / k / M）、经验条解析、吃糖顺序、买糖估价与预算边界。

### 3.8.1

- **修正商店模块的事实错误**：钱店是固定货架（不刷新），且不卖树果。旧版 `SHOP_BERRY_IDS` 把 `BERRY_BADGES` 里的树果 id 误当成货架商品，导致「补货」永远找不到对应行、实际什么都没买。
- 按真实货架重写（bundle 里 `Ke.SHOP` 常量，28 件）：经验糖 s/m/xl/big（1,200 / 7,200 / 48,000 / 96,000 ₽，徽章门槛 0/3/6/8）、进化石 10 万、一次性进化道具 50 万。
- 采购策略：在买得起的档位里取「每 ₽ 经验」最高的一档（big 10.4 > xl 5.21 > m 2.08 > s 0.83），档位锁着自动顺延下一档；每轮只买一件；受金钱下限与每日上限双重保护。
- 新增 `shopBuyOneOff`（默认关）：顺便买 50 万的一次性进化道具，买过的自动跳过。
- 修掉一处同类时间戳 bug：`shopMissAt` / `shopHintAt` / `shopOpenTriedAt` 用 `x || 0` 当「从未提醒过」，会把页面刚加载的头 10 分钟也压住，改为判空。
- 设置面板分组改名「商店采购（经验糖 · 固定货架不卖树果）」，去掉树果保留数；离线自测扩到 101 项。

### 3.8.0

- 新增「战斗对位卡」：`battleProbe()` 从 `#arena .enemy[data-uid]`、`#team-rail .tr-row` 读双方血量（只认 `style.width` 的百分比，改 px 时一律按满血处理，避免误判残血天天抢操作），`btForecast()` 用脚本自带的伤害表算回合数、先手与胜率。
- 新增「智能换人」：`btBenchCandidates()` 按对位胜率排序替补，`smartSwitch()` 在本场胜率低于阈值或残血时换人；同时接管原来的「残血自动换人」，避免两套逻辑抢同一个按钮。
- 新增「区域战绩」：按 `adv.chapter:adv.node` 记胜负、平均掉血与用时，最多保留 60 个区域；连败到阈值时日志 + 通知 + 手机推送，10 分钟最多一次。
- 新增「首发建议」：`btLeadPick()` 用区域敌人池 + `taEvaluate()` 打分，「按当前区域重排首发」按钮通过合成 PointerEvent 拖拽 `.tr-row`，1.2 秒后复核顺序并如实报告成功或失败。
- 新增「战斗探测」按钮：输出双方、预测、区域战绩、`#arena`/`#team-rail` 节点数量与日志尾段，游戏改版时先用它定位。
- 离线自测扩到 90 项断言，新增覆盖血条解析、对位预测、替补筛选、战绩记账、连败提醒、战斗结算、首发建议与对位卡渲染。
